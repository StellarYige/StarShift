星易 StarShift v0.1.1：发布方式清理、DOCX 进度与故障恢复、浏览器资源释放修复。

- 停止提供项目静态 ZIP 与校验附件，清理 v0.1.0 的手工附件及 Actions 项目包；保留标签、版本记录、Pages 部署和工具中的转换结果 ZIP 下载。
- DOCX 展示检查、资源加载、初始化、排版和导出阶段，区分下载、初始化、兼容性、文档及超时错误；引擎级失败停止本批并保留输入供重试。
- 保持同批串行复用、每批结束释放，不常驻引擎，不更换引擎或中文字体。没有引入未经成对实测验收的性能优化。
- 修复损坏 PDF 的 Worker 清理、预览旧状态、重复 ZIP URL 增长和取消后异步状态竞争；提供 ZIP 准备完成后的直接下载链接。
- 为缺少 Worker Canvas 的浏览器增加本地图片回退，补齐窄屏预览／下载按钮的可访问名称；保持定时器原有回调上下文。
- 修复首屏 hash 工具切换竞争与横屏预览底部操作裁切。
- 清空时彻底释放工作区持有的 File / Blob 并保留设置；提前检查已实测的引擎能力要求，避免不兼容浏览器反复分配 WASM 内存。
- Actions 官方组件升级至已核对的 Node 24 运行时版本并固定提交 SHA，不升级无关 npm 依赖。

[在线使用](https://stellaryige.github.io/StarShift/) · [从源码构建和自行部署](https://github.com/StellarYige/StarShift/tree/v0.1.1#自行部署) · [完整实测、兼容限制与部署记录](https://github.com/StellarYige/StarShift/blob/v0.1.1/docs/V0.1.1_REPORT.md)

当前固定 DOCX 引擎在所测 Firefox / Windows WebKit 中存在兼容限制；不兼容提示与其他工具的测试结果分别记录，不算 DOCX 转换通过。手机模拟不等于真机；真实 Android、iPhone 和 macOS Safari 项目保留为[人工待验证](https://github.com/StellarYige/StarShift/blob/v0.1.1/docs/MOBILE_MANUAL_CHECKLIST.md)。复杂 Word 排版仍需预览核对。

重复性能测量仍出现偶发初始化失败／超时，尚未确定根因；超时后可保留输入显式重试。原始失败与成功样本均保留在报告中，本版没有稳定提速的结论。

验证结果：7 项单元、原有 14 项回归在本地两种部署路径和线上均通过；本机浏览器矩阵 84 项通过、18 项明确跳过，线上 248 个资源路径通过。修订版线上 21 批性能样本全部成功，冷启动／再次访问／连续批次中位数为 28.522／10.568／9.037 秒，旧版为 36.119／9.508／8.046 秒（另有一次冷启动失败）；本地最终 35 批有一次初始化超时，均如实记录。所测中文样例两页渲染结果与旧版一致。
